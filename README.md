# Битва за Рокуган

Полная базовая партия для 2–5 человек: локально с передачей устройства или через сетевую комнату. Реализованы 30 провинций, семь кланов с их наборами из 27 жетонов, подготовка, 12 тайных целей, пять раундов, инициатива, все 22 варианта карт территорий и итоговый подсчёт.

Проект подготовлен к подключению к Zarya Boardgames: `zarya-game.json`, `Dockerfile`, `compose.yaml` и обёртка `deploy.sh`. Порядок регистрации и проверенный API описаны в [docs/SITE-INTEGRATION.md](docs/SITE-INTEGRATION.md). Исходники: [Sabberian/battle-for-rokugan-boardgame](https://github.com/Sabberian/battle-for-rokugan-boardgame). Подключение к живому сайту выполняется владельцем платформы; [порядок передачи](docs/PUBLISHING.md).

## Запуск

Нужны Node.js 22+ и npm. Из этой папки:

```sh
npm.cmd ci
npm.cmd run build
npm.cmd run serve
```

Откройте http://localhost:3001. Для Windows также доступен `Start-Rokugan.ps1`: он устанавливает зависимости при первом запуске, собирает приложение и запускает сервер в текущем терминале. Остановка — Ctrl+C.

Для разработки клиента: `npm run dev` (порт 5173). Сервер запускается отдельно; после изменения движка или сервера повторите сборку и перезапустите его.

## Как начать

1. Выберите 2–5 участников и локальную партию либо создайте сетевую комнату.
2. В сети передайте друзьям ссылку-приглашение. Каждый вводит имя, занимает свободное место и выбирает клан. Как в «Кикладах», хозяин начинает партию после заполнения мест, без отдельной кнопки готовности. Для наблюдения предусмотрена отдельная ссылка зрителя. `localhost` доступен только на компьютере, где запущен сервер.
3. В лобби каждый выбирает карту клана. Первый участник (хозяин) может нажать «Случайно»: уже выбранные кланы сохраняются, оставшиеся распределяются случайно. Если клан не выбран к старту, он тоже раздаётся случайно. После запуска каждый выбирает одну из двух тайных целей. Затем игроки по очереди занимают свободные провинции.
4. Выберите жетон в руке и нажмите центр провинции или маркер общей границы прямо на карте. Повторное нажатие границы меняет направление атаки; морские границы помечены волной. Подтвердите размещение. Жетоны остаются на поле: чужие закрыты рубашкой. Разведчик и сюгэндзя доступны после выбора приказа на карте; карта первого игрока — в списке приказов. Карты территорий и способности кланов появляются в соответствующей фазе.
5. Раскрытие показывает все приказы, затем последовательно обновляет только провинции с поставленными приказами. Первый игрок управляет автоматическим показом, паузой или переходом к следующей провинции. Все сетевые клиенты видят один и тот же шаг. Бои рассчитаны одновременно по владениям до раскрытия. После показа первый игрок запускает следующий раунд. После пятого раунда открываются цели, очки и победитель.

Карты с тайным просмотром или возвратом жетонов используют отдельный шаг завершения. Блеф с намеренно неверным типом жетона допустим; такие приказы убираются при раскрытии. Подробности — в справке интерфейса и [официальных правилах](https://images-cdn.fantasyflightgames.com/filer_public/95/ef/95ef7efa-c0e1-4ae9-bd33-5439d236cefb/l5b01_rulebook_webcompressed.pdf).

## Сохранения и скрытая информация

- Локальная партия автоматически сохраняется в этом браузере. После обновления страницы нажмите «Продолжить локальную партию». Новая партия создаёт отдельное сохранение и становится последней в меню.
- Сетевые партии хранятся сервером в `data/matches`. Ключ вашего места сохраняется в браузере. Для возвращения введите тот же код комнаты в том же браузере.
- Сервер скрывает чужие руки, цели, будущую инициативу, резерв, нераскрытые карты территорий и результаты чужой разведки. Аргументы ходов удаляются из чужих журналов. Undo отключён.
- Локальная ширма защищает от случайного просмотра при передаче устройства. Владелец компьютера имеет доступ к локальному сохранению; для независимых игроков используйте сервер.

- Армия, флот, синоби, благословение, набег, дипломатия и блеф.

- Мир, выжженная земля, святилище, поле битвы, порт, бонусы чести и защиты.
- Одновременные захваты; инициатива и ничьи; ронины; перенос оставшегося жетона; передача неиспользованных карт территории.
- Все цели и окончательный подсчёт, включая общую победу при полном равенстве.

Оформление использует настоящее поле с интерактивными провинциями, масштабированием и фильтром территорий. Добавлены изображения ширм семи кланов, жетонов, всех 12 целей и 20 карт территорий; картинки открываются крупно по нажатию. Источники — в [описании изображений](packages/client/public/art/SOURCES.md). Для двух карт (`pirates`, `spy`) в исходном наборе нет сканов: используется текстовое оформление с игровыми значениями. Боевые жетоны используют оригинальные изображения с обрезкой по контуру; для отсутствующего скана синоби Скорпиона силой 3 оставлен SVG-значок. Рубашка территорий извлечена из официальной книги правил.

Официальные дополнения именно к Battle for Rokugan в изученных материалах не найдены; Земли Тени входят в базу. Black Rose Wars остаётся отдельной будущей задачей; текущий интерфейс посвящён Рокугану.

## Проверки

```sh
npm test
npm run check
npm run build
# При работающем сервере:
node scripts/full-net-test.cjs
```

110 автоматических тестов: боевые комбинации, способности кланов, эффекты всех карт, цели, закрытая информация и 16 полных симулированных партий на 2–5 игроков с разными случайными наборами. Сетевой тест проходит полную партию тремя Socket.IO-клиентами, проверяет зрителя, журналы и восстановление клиента. Тестовые комнаты остаются в локальном хранилище.

После обновления оформления в браузере проверены создание комнаты, вход второго игрока, готовность, старт хозяином, выбор кланов, изображения целей, увеличение картинок и масштабирование поля. Консоль не показала ошибок. Проверен мобильный экран 390 px: горизонтального переполнения нет. Также проверены ручные укрепления, размещение на границе, пауза и шаг раскрытия, одинаковый шаг у зрителя. Реальные длительные партии людей всё равно полезны для проверки удобства и редких сочетаний решений.

## Структура

- `packages/engine/src/content.ts` — карта, кланы, жетоны, цели и карты территорий.
- `packages/engine/src/full-game.ts` — автомат полной партии, транзакции ходов и приватные проекции.
- `packages/engine/src/rules.ts` — размещение, разведка, разрешение боя и базовая честь.
- `packages/client` — React/Vite, игровая ширма, формы карт, карта и комнаты.
- `packages/server` — boardgame.io, Socket.IO, FlatFile и `/health`.
- `docs/RULES-RESEARCH.md` — источники и решения по дополнениям.
- `docs/MERGE-REQUEST.md` — описание для будущего MR.

Стенд `rokugan-combat-lab` оставлен как отдельный диагностический сценарий; пользовательский интерфейс запускает `battle-for-rokugan`.

Настройки сервера: `PORT` (3001), `MATCHES_DIR`, `ALLOWED_ORIGINS` (разрешённые адреса браузерных клиентов через запятую). Для размещения на другом домене укажите его origin. Клиент поддерживает `?name=<ник>&embed=1` и приглашения `#/m/<код>`. Для установки на платформу необходимо настроить HTTPS, постоянное хранилище матчей и маршрутизацию WebSocket. По образцу существующих проектов добавлены служебные маршруты, включаемые только переменной `PLATFORM_SECRET`: `POST /platform/matches/:id/leave` с JSON `{ "playerName": "Имя" }` и `DELETE /platform/matches/:id`. Оба требуют заголовка `x-platform-secret`. Секрет задаётся только на сервере.

## Игровой стол и свободный режим

Карта открывается по ширине стола; её можно прокручивать и масштабировать. «Всё поле» показывает карту целиком. Собственные карты расположены под полем слева: нажмите карту, затем «Использовать» и выберите цель на поле или игрока в списке. Для условных эффектов запрашиваются только необходимые цели. Карты соперников показаны под их именами рубашкой вверх. Тайная цель скрыта в блоке справа снизу. Секции карт можно свернуть, изображения можно увеличить.

В лобби нет настройки свободного управления. Во время партии любой участник может включить его кнопкой «Ручное управление» и затем нажать «Вернуться к правилам». В этом режиме участники вручную меняют владельца и открытый контроль выбранной провинции, кладут свои жетоны без ограничений размещения и возвращают их в руку. Для переноса выберите приказ, затем новое место на поле и «Переместить сюда». В ручном режиме можно перемещать и возвращать чужие приказы, но скрытая рука остаётся недоступной. Свой приказ можно заменить жетоном из своей руки. «Отменить последнее действие» восстанавливает состояние до последнего игрового действия, в том числе если ручной режим включили уже после него. Снимок для отмены хранится только на сервере и не передаётся клиентам. Изменения записываются в журнал; скрытые руки остаются скрытыми. В разделе «Передать ход» можно выбрать участника. Хозяин может досрочно запустить автоматический расчёт боёв. Во время раскрытия и незавершённых эффектов карт доступна отмена; остальные ручные правки выполняются после завершения такого эффекта. Автопоказ раскрытия при включённом ручном режиме останавливается.

По официальным правилам, стр. 7 и 9, карты территорий не выдаются после стартового размещения: их впервые получают в конце первого раунда. На первом ходу шаг розыгрыша карт территорий пропускается.

Соседства исправлены по скану: добавлены 2–4, 5–8 и 6–7, удалены 4–5, 4–8 и 11–23. Координаты доступных границ находятся в packages/engine/src/board.ts и используются одновременно картой и движком.

После обновления остановите старый сервер (Ctrl+C), выполните `npm.cmd run build` и `npm.cmd run serve`, обновите страницу и создайте новую партию. Старые сохранения содержат прежние соседства и настройки раскрытия; автоматически они не переписываются.

## Управление мышью и читаемость

Перетаскивайте поле левой кнопкой мыши: текст и картинки не выделяются, перетаскивание не считается нажатием на провинцию. Стартовый масштаб — 100%; он сохраняется при передаче хода и закрытии локальной ширмы. Нажатие процента возвращает 100%.

При выборе жетона подсвечиваются подходящие центры и границы. На сухопутной границе единственное доступное направление выбирается автоматически; стрелки появляются только при двух вариантах или в свободном режиме. В свободном режиме ограничения размещения снимаются. Блеф сохраняет возможность нестандартного размещения. Метки размещения рисуются поверх жетонов; благословение можно поставить через отдельную звезду возле подходящего приказа.

Боевые жетоны и контроль используют оригинальные изображения компонентов внутри SVG. Наведение или клавиатурный фокус на благословлённой стопке раздвигает её; чужой неизвестный приказ остаётся рубашкой вверх. Добавление, снятие, перенос и смена контроля анимированы с учётом системной настройки уменьшения движения.

Карты открываются крупно, с кнопками увеличения и уменьшения. Описание эффекта показано отдельным читаемым текстом; подсказка доступна при наведении или фокусе на карточке.

Скорпион: нажмите «Тайный взгляд», выберите незащищённый приказ на поле, затем разместите свой жетон. Один раз за раунд, во время своего размещения, выбранный приказ открывается на поле только для вас. Благословение защищает от просмотра. После просмотра передайте ход.


## Итоги и обзор владений

После пятого раунда автоматически открывается окно победителя. При равенстве очков оно объясняет дополнительное условие победы. Нажмите клан в итоговой таблице: появятся статус тайной цели и очки каждого региона. Строка региона раскрывается до отдельных провинций, их чести и открытого контроля. Расшифровка и общий счёт используют одну функцию расчёта. Окно можно закрыть для осмотра поля и открыть снова.

Наведение на игрока в списке выделяет метки его владений на поле и приглушает остальные; доступно также с клавиатурным фокусом. Кнопки увеличения карт заменены лупами в правом верхнем углу.


## Разработка: быстрый доступ к середине партии

`npm run dev`, затем откройте `http://127.0.0.1:5173/?autoplay=3&nocurtain#/local` (работает только в режиме разработки):

- `autoplay=N` — локальная партия сама проходит лобби, цели, драфт и раунды до начала раунда N, а сохранённая партия открывается сразу;
- `nocurtain` — без шторки «Передайте устройство» между ходами;
- в консоли браузера `window.__rk` — клиенты игроков (`__rk[0].moves.act({...})`).

## Ассеты, собранные скриптами

- `python tools/fit_provinces.py --preview out.png` — контуры провинций по скану поля (компьютерное зрение: линии границ → водораздел от точек провинций), пишет `regions` в `public/art/board-points.json`;
- `python tools/clear_token_backgrounds.py` — прозрачный фон у сканов особых жетонов;
- `python tools/make_missing_cards.py` — карты «Пиратские набеги» и «Шпионская сеть», которых нет среди сканов.
